# ГеоКамера для Android

Приложение снимает местность и печатает на фото координаты точки съёмки, высоту, азимут, время и вашу заметку. Готовое фото можно открыть и поправить любое поле. Сохранённые фото лежат в галерее, в папке GeoCamera.

Страница приложения лежит в `app/src/main/assets/index.html`. Android-часть (`MainActivity.java`) даёт ей камеру, GPS и сохранение в галерею.

## Как получить APK на компьютере

1. Установите Android Studio (бесплатно, developer.android.com/studio).
2. Запустите её, выберите **Open** и укажите эту папку (`GeoCamera-android`).
3. Дождитесь, пока внизу закончится синхронизация Gradle. При первом запуске она скачивает около 1 ГБ.
4. В меню: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Когда появится сообщение «APK(s) generated successfully», нажмите **locate**. Файл называется `app-debug.apk`.

## Как установить на телефон

1. Перенесите `app-debug.apk` на телефон (кабель, мессенджер, облачный диск).
2. Откройте файл на телефоне. Android попросит разрешить установку из этого источника. Разрешите.
3. При первом запуске разрешите камеру и геопозицию, затем нажмите «Запустить».
4. Включите GPS и для точных координат выйдите на открытое место.

Это отладочная сборка для проверки. Магазин приложений её не примет, для него нужна подпись релизной версией.

## Сборка без установки Android Studio

Если у вас есть аккаунт на GitHub: создайте репозиторий, загрузите в него содержимое этой папки, откройте вкладку **Actions**, выберите **Build APK** и нажмите **Run workflow**. Через несколько минут APK можно скачать из раздела Artifacts.

## Что работает и что не проверено

Проект не собирался и не запускался на телефоне: в среде, где он создан, нет Android SDK. Если сборка выдаст ошибку, пришлите её текст, и её можно будет исправить.
