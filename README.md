# Радуль Лиман

Приложение для Android и iPhone. Снимает местность и печатает на фото координаты точки съёмки, высоту, точность, время и заметку. В списке приложений оно называется «Калькулятор», выглядит как калькулятор и открывается по коду.

## Что умеет

- Координаты вида `55.343434, 45.343435` на экране камеры и на готовом снимке. Кнопка «DD» переключает на градусы, минуты, секунды.
- Поле заметки под координатами. Текст попадает на фото.
- Перекрестие по центру кадра: кнопка вкл/выкл, размер, толщина и цвет (на экране камеры и в редакторе).
- Редактор снимка: стрелки, круги, рисование от руки, перекрестие. У каждой фигуры можно менять цвет, размер и толщину. Выбранную фигуру можно передвинуть, потянув за неё. У круга белая точка на кольце меняет радиус, у стрелки две точки двигают начало и конец. Есть отмена действий.
- «Сохранить» оставляет снимок внутри приложения, закрывает редактор и показывает сообщение. В галерею телефона снимок не попадает сам.
- «В галерею» (в редакторе снимка и в списке снимков, где можно выбрать сразу несколько) копирует готовое фото в галерею телефона. Если поставить галочку «Убрать из приложения после переноса», снимок уйдёт из приложения. Перенесённые снимки помечены «в галерее».
- В настройках можно выключить дату и время: они пропадут с экрана камеры и с фото (в том числе со старых снимков).
- Все поля подписи (координаты, заметка, высота и точность, дата) правятся в редакторе. Азимута в подписи нет.
- Снимки хранятся внутри приложения. В списке снимков их можно выбрать (долгое нажатие), перенести в галерею или удалить. При удалении можно заодно стереть копии из галереи телефона (папка `Pictures/RadulLiman`).
- Калькулятор и код: см. раздел ниже. Настройки открываются кнопкой с замком на экране камеры.

## Как собрать APK

На GitHub: вкладка **Actions** → **Build APK** → **Run workflow**. Сборка запускается и сама после каждого изменения в ветке `main`. Готовый файл лежит внизу страницы запуска, в разделе **Artifacts**, под именем `RadulLiman-debug-apk`.

На компьютере: откройте папку проекта в Android Studio и выполните **Build → Build APK(s)**.

## Как собрать IPA для iPhone

На GitHub: вкладка **Actions** → **Build iOS IPA** → **Run workflow** (запускается и сама при изменениях в `main`). Файл `RadulLiman.ipa` лежит в разделе **Artifacts** под именем `RadulLiman-ipa`.

IPA собирается **без подписи Apple**, поэтому напрямую на iPhone он не установится. Его нужно подписать своим Apple ID одной из программ для установки со стороны: AltStore, Sideloadly и похожие. Бесплатный Apple ID даёт подпись на 7 дней, потом приложение надо переустановить (данные при установке поверх сохраняются). Платный аккаунт разработчика (99 долларов в год) даёт подпись на год и установку через TestFlight.

Тот же `index.html`, что и на Android, лежит внутри приложения. Часть для iPhone: `ios/RadulLiman/*.swift`. Она даёт странице камеру, координаты (CoreLocation), перенос в «Фото», удаление копий и меню «Поделиться». Проект Xcode создаётся программой XcodeGen из `ios/project.yml`. Собирать можно только на Mac (или на macOS-машине GitHub, как сейчас).

Фото из iPhone-версии сохраняются в приложение «Фото» (папки отдельной нет). Все остальные возможности те же.

## Обновление поверх старой версии

Все сборки подписаны одним и тем же ключом (`app/debug.keystore`), поэтому новую версию можно ставить поверх старой, снимки сохранятся. Исключение: версию, собранную до появления этого ключа, нужно один раз удалить перед установкой. Снимки той версии при этом пропадут, поэтому сначала сохраните нужные в галерею телефона.

Ключ учебный и лежит в открытом репозитории. Для магазина приложений и для приложения с важными данными он не подходит.

## Калькулятор и код

- Иконка и название приложения: «Калькулятор». При запуске открывается обычный рабочий калькулятор (сложение, вычитание, умножение, деление, проценты, смена знака, стирание цифры смахиванием или кнопкой).
- При самом первом запуске приложение предлагает придумать код из 4 цифр и повторить его. Пока код не задан, дальше пустить оно не может.
- Чтобы открыть приложение, наберите код на калькуляторе и нажмите «=». Любой другой набор просто считается как обычное вычисление.
- Калькулятор показывается при каждом запуске и когда вы возвращаетесь в приложение больше чем через 30 секунд. Кнопка с калькулятором на экране камеры прячет приложение сразу.
- Код можно сменить в настройках (нужен текущий код). Убрать его нельзя.
- Если у вас стоял пароль из версии 2.1, он вводится один раз в обычном окне. Если он состоял из 4–12 цифр, дальше он сам работает как код на калькуляторе. Если в нём были буквы, после входа откроются настройки, где нужно задать новый код из 4 цифр.
- Код хранится в виде хеша (PBKDF2). Он закрывает вход в приложение, но не шифрует сами снимки на телефоне. Забытый код восстановить нельзя: придётся удалить данные приложения, и снимки пропадут.
- На Android 13 и новее в списке недавних приложений не показывается снимок экрана. На iPhone при уходе из приложения окно закрывается чёрной шторкой.
- Папка в галерее называется `RadulLiman`, это название видно в галерее телефона.

## Устройство проекта

Страница приложения лежит в `app/src/main/assets/index.html` (общая для Android и iPhone). Android-часть (`MainActivity.java`) даёт ей камеру, GPS, перенос в галерею, удаление копий и сообщает странице, сколько приложение пробыло в фоне, чтобы она могла снова показать калькулятор.
