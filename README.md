# Радуль Лиман

Приложение для Android. Снимает местность и печатает на фото координаты точки съёмки, высоту, азимут, время и заметку.

## Что умеет

- Координаты вида `55.343434, 45.343435` на экране камеры и на готовом снимке. Кнопка «DD» переключает на градусы, минуты, секунды.
- Поле заметки под координатами. Текст попадает на фото.
- Перекрестие по центру кадра: кнопка вкл/выкл, размер, толщина и цвет (на экране камеры и в редакторе).
- Редактор снимка: стрелки, круги, рисование от руки, перекрестие. У каждой фигуры можно менять цвет, размер и толщину, выбранную фигуру можно передвинуть или убрать. Есть отмена действий.
- Все поля подписи (координаты, заметка, высота, дата) правятся в редакторе.
- Снимки хранятся внутри приложения. В галерее приложения их можно выбрать (долгое нажатие) и удалить. При удалении можно заодно стереть копии из галереи телефона (папка `Pictures/RadulLiman`).
- Пароль на приложение: настройки открываются кнопкой с замком на экране камеры.

## Как собрать APK

На GitHub: вкладка **Actions** → **Build APK** → **Run workflow**. Сборка запускается и сама после каждого изменения в ветке `main`. Готовый файл лежит внизу страницы запуска, в разделе **Artifacts**, под именем `RadulLiman-debug-apk`.

На компьютере: откройте папку проекта в Android Studio и выполните **Build → Build APK(s)**.

## Обновление поверх старой версии

Все сборки подписаны одним и тем же ключом (`app/debug.keystore`), поэтому новую версию можно ставить поверх старой, снимки сохранятся. Исключение: версию, собранную до появления этого ключа, нужно один раз удалить перед установкой. Снимки той версии при этом пропадут, поэтому сначала сохраните нужные в галерею телефона.

Ключ учебный и лежит в открытом репозитории. Для магазина приложений и для приложения с важными данными он не подходит.

## Пароль

Пароль хранится в виде хеша (PBKDF2). Он закрывает вход в приложение, но не шифрует сами снимки на телефоне. Забытый пароль восстановить нельзя: придётся удалить данные приложения, и снимки пропадут.

## Устройство проекта

Страница приложения лежит в `app/src/main/assets/index.html`. Android-часть (`MainActivity.java`) даёт ей камеру, GPS, сохранение в галерею, удаление копий и сообщает странице, сколько приложение пробыло в фоне, чтобы она могла запросить пароль.
